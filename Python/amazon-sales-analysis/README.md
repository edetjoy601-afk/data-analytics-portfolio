
# Amazon Sales Exploratory Data Analysis

## Overview
This project uses Python to explore Amazon sales data, practice data preparation, and identify patterns in the available records.

## Objectives
- Inspect the dataset.
- Identify missing values and duplicates.
- Prepare the data for analysis.
- Explore relevant sales variables.
- Summarize findings using tables and visualizations.

## Tools
- Python
- Jupyter Notebook
- pandas
- matplotlib and seaborn

## Methodology
1. Imported the dataset and relevant Python libraries.
2. Inspected columns, data types, and summary statistics.
3. Checked data quality.
4. Performed exploratory analysis.
5. Created visualizations and summarized findings.

## Exploratory Analysis
- Analyzed monthly sales trends to understand how performance changes over time
- Evaluated product category performance in terms of sales and profit
- Explored customer purchasing behavior
- Performed correlation analysis to understand relationships between key variables


## Key Findings
- Sales fluctuate across different months
- High sales don’t always mean high profit
- Customers tend to buy in small quantities (mostly between 1- 5 items)
- Quantity sold has a strong impact on overall revenue
