
# Pharmaceutical Sales Performance Analysis

## Overview
This project analyzes pharmaceutical sales data using Microsoft Excel to organize sales information and support performance reporting.

## Objectives
- Clean and prepare the dataset.
- Correct inconsistent text and numeric values.
- Handle blank or missing values appropriately.
- Summarize sales performance using PivotTables.
- Present results in a clear, understandable format.

## Tools
- Microsoft Excel
- Spreadsheet formulas
- Data cleaning
- PivotTables and reporting

## Methodology
1. Inspected the dataset and identified data quality issues.
2. Cleaned text fields and standardized values.
3. Checked numeric fields and handled blanks.
4. Created summaries using PivotTables.
5. Reviewed the results for consistency.

## Key Findings
After analyzing the pharmaceutical sales dataset in Microsoft Excel, I was able to:

- Product Performance: Identify the products generating the highest total sales.
- Country Performance: Determine the best-performing country based on revenue.
- Yearly Sales Trends: Analyze annual sales trends to observe changes in performance over time.
- Top and Bottom Performers: Identify the highest- and lowest-performing products.
- Overall Sales: Calculate the total sales value across the dataset.
